# Gestion-de-torneos-deportivos
Aplicacion para crear y gestionar torneos y sus participantes

Funcionalidades:

- Crear torneos.
- Registrar equipos o participantes.
- Inscribir equipos en torneos.
- Consultar partidos.
- Registrar resultados.
- Consultar posiciones/resultados.
- Los organizadores pueden gestionar sus torneos.

Entidades:

- Usuario
- Torneo
- Equipo
- Jugador
- Partido

Autorización: solamente el creador/organizador de un torneo puede modificar sus partidos y resultados.
